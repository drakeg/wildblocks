# Original game direction

Wildblocks uses an original implementation and original or independently licensed assets. It does not depend on another game’s installations, accounts, data, or licenses.

The repository contains the voxel client, desktop wrapper, authoritative multiplayer server, tests and packaging tools. Third-party Three.js code retains its MIT notice in `dist/vendor/THREE-LICENSE.txt`; packaged Electron and Node runtimes include their notices. The project's own code currently retains its existing `UNLICENSED` designation; public visibility does not assign it an open-source license.

Any separate fantasy RPG is outside this repository. Earlier game reverse-engineering research and third-party game downloads are not dependencies and are not included.
